# QingMan 青漫

基于 HarmonyOS（ArkTS）的开源漫画 & 小说阅读器。通过可自定义的书源规则抓取网站内容，支持漫画在线阅读与小说书架管理。

## 功能特性

- 📚 **书源系统** — 支持自定义书源导入，内置规则引擎（CSS 选择器 / JsonPath / HTML 解析），兼容「开源阅读」风格的书源规则
- 📖 **小说阅读** — 书架管理、书籍详情、目录跳转、正文阅读
- 🖼️ **漫画阅读** — 漫画搜索、详情、章节列表、在线阅读
- 🔍 **发现页** — 分类浏览、探索页聚合
- ⚙️ **书源管理** — 书源增删改查、剪贴板一键导入
- 🎨 **阅读设置** — 个性化阅读配置

## 技术栈

- **语言**：ArkTS
- **框架**：ArkUI（声明式 UI）
- **SDK**：HarmonyOS SDK 26
- **架构**：Navigation 路由 + 系统路由表（router_map）
- **存储**：关系型数据库（RDB）+ Preferences

## 项目结构

```
entry/src/main/ets/
├── analyze/     # 规则引擎（CSS 选择器、JsonPath、HTML 解析、规则分析）
├── service/     # 业务服务（HTTP 客户端、书源仓库、搜索、数据库）
├── model/       # 数据模型
├── pages/       # 页面（书架、搜索、阅读、书源管理等）
├── components/  # 公共组件
└── common/      # 通用工具
```

## 构建与运行

1. 安装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（API 26 及以上）
2. 打开项目根目录，等待依赖同步
3. 连接鸿蒙设备或启动模拟器
4. 点击 Run 或执行命令行构建：

```bash
devecocli build
devecocli run --skip-build
```
